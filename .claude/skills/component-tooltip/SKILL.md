# Tooltip (확인 필요)

이 스킬은 이전에 React `Tooltip` 컴포넌트를 기준으로 작성되어 있었지만, 이 프로젝트는 정적 HTML·SCSS 퍼블리싱 보일러플레이트라 그 내용이 맞지 않는다.

## 작업 전 확인 절차

1. `src/guide/pages/components/tooltip.html`을 읽어 실제 마크업 구조, 클래스명, 열림/닫힘(hover, focus, 클릭) 처리 방식을 확인한다.
2. 확인한 구조를 바탕으로 구현하고, 이 스킬 문서를 실제 마크업 기준으로 갱신한다.
3. 구조가 불명확하면 추측하지 말고 사용자에게 확인한다.
