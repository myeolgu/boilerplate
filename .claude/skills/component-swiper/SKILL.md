# Swiper (확인 필요)

이 스킬은 이전에 `swiper/react`(React 래퍼) 기준으로 작성되어 있었지만, 이 프로젝트는 React가 아닌 정적 HTML·SCSS 퍼블리싱 보일러플레이트다. 순수 JS Swiper 라이브러리를 쓰는지, 다른 방식인지 확인되지 않았다.

## 작업 전 확인 절차

1. `src/guide/pages/components/swiper.html`을 읽어 실제 마크업 구조와 사용 중인 스크립트(순수 Swiper JS인지, 자체 구현인지)를 확인한다.
2. 확인한 구조를 바탕으로 구현하고, 이 스킬 문서를 실제 마크업·초기화 코드 기준으로 갱신한다.
3. 구조가 불명확하면 추측하지 말고 사용자에게 확인한다.
