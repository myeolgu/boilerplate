# Modal (확인 필요)

이 스킬은 이전에 React `@/components/ui/Modal` 컴포넌트를 기준으로 작성되어 있었지만, 이 프로젝트는 정적 HTML·SCSS 퍼블리싱 보일러플레이트라 그 내용이 맞지 않는다. 실제 마크업 규칙은 아직 정리되지 않았다.

## 작업 전 확인 절차

1. `src/guide/pages/components/modal.html`을 읽어 실제 마크업 구조, 클래스명, `data-*` 속성, 열림/닫힘 처리 방식을 확인한다.
2. 확인한 구조를 바탕으로 구현하고, 이 스킬 문서를 실제 마크업 기준으로 갱신한다.
3. 구조가 불명확하거나 `dialog.html`(알림/확인창)과 어떻게 구분되는지 애매하면 추측하지 말고 사용자에게 확인한다.

## 참고

- `src/guide/pages/components/dialog.html`도 함께 확인한다. 확인·경고 팝업이 필요한 경우 모달과 다이얼로그 중 어느 패턴이 맞는지 구분해야 한다.
